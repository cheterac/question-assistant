# Установка с флешки на Linux

1. Скопируйте dist/otvet-ryadom-cloud-2.0.0.zip с флешки на компьютер. Распакуйте в постоянную папку. В её корне должен лежать manifest.json.
2. В Chrome или Chromium откройте chrome://extensions, в Edge — edge://extensions. Включите режим разработчика, нажмите «Загрузить распакованное расширение» и выберите эту папку. В управляемом браузере администратор может запретить такую установку.
3. Откройте параметры расширения и введите свой [ключ Groq](https://console.groq.com/keys). После перезапуска браузера введите его снова. На флешке ключа нет.
4. Прокрутите страницу так, чтобы нужный вопрос был виден. Нажмите Alt + Shift + Q или значок расширения. Проверьте миниатюру и нажмите «Отправить снимок в Groq». Разверните ответ для продолжения разговора. Щелчок вне окна закрывает его и завершает чат. Если сочетание занято, переназначьте его на странице сочетаний клавиш браузера.

Окно открывается у панели инструментов браузера. Захватывается видимая область текущей HTTP(S)-вкладки. В запросе нет отдельного поля с адресом страницы, но всё видимое на изображении, включая личные данные, будет передано в Groq. При каждом уточнении расширение отправляет тот же снимок и историю текущего чата. Снимок и переписка существуют в памяти окна. Ключ хранится в session storage расширения. У провайдера собственные правила обработки и возможного временного хранения запросов. [Обработка данных Groq](https://console.groq.com/docs/your-data)

Используется модель qwen/qwen3.8-27b. Один снимок учитывается как 2048 входных токенов. Бесплатный доступ ограничен квотами аккаунта. Нужны интернет и доступ к Groq с этого устройства. [Vision API](https://console.groq.com/docs/vision) · [Квоты](https://console.groq.com/docs/rate-limits)

Для публикации используйте ZIP облачной версии, опишите разрешения activeTab, storage и доступ к api.groq.com, разместите публичную политику с описанием передачи снимков и чата в Groq. Политика локальной версии для этой сборки не подходит. В магазине облачная версия пока не опубликована.
