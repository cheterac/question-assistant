# Ответ рядом

**Linux / Chromium, ответ по скриншоту через облако:** [инструкция и приватность](CLOUD.md) · [ZIP для флешки](dist/otvet-ryadom-cloud-2.0.0.zip). Ниже описана отдельная локальная версия.

Настольное расширение для вопросов по выделенному тексту. Работает с локальной Ollama и моделью Qwen3 4B Instruct. Исходники в `extension/` уже готовы к загрузке, компиляция и зависимости JavaScript не нужны.

## Chrome и Microsoft Edge

1. Откройте `chrome://extensions` или `edge://extensions`, включите режим разработчика, нажмите «Загрузить распакованное» и выберите **папку extension**, в которой лежит manifest.json. Если получили ZIP, сначала распакуйте его.
2. Откройте параметры расширения из его карточки. Можно также открыть «Настройка» в окне ответа. Страница параметров показывает команду с точным адресом origin этой установки.
3. Выполните настройку Ollama ниже. На обычной веб-странице выделите вопрос, нажмите **Alt + Shift + Q** (на Mac **Option + Shift + Q**) или значок расширения. Для смены клавиш используйте `chrome://extensions/shortcuts` или `edge://extensions/shortcuts`. При конфликте сочетаний назначьте свободное. [Команды Chrome](https://developer.chrome.com/docs/extensions/reference/api/commands), [локальная установка в Edge](https://learn.microsoft.com/en-us/microsoft-edge/extensions/getting-started/extension-sideloading).

## Ollama

1. Установите [Ollama](https://ollama.com/download). Если сервер уже работает как приложение, завершите его перед запуском другой копии на том же порту.
2. На macOS и Linux запустите команду из параметров расширения. Она задаёт `OLLAMA_ORIGINS` для текущей установки, `OLLAMA_HOST=127.0.0.1:11434` и `OLLAMA_NO_CLOUD=1`. Оставьте терминал открытым. Если используете несколько браузеров, перечислите их точные origin через запятую. Для службы задайте те же переменные в окружении службы и перезапустите её. [Настройка сервера и разрешённых origin](https://docs.ollama.com/faq).
3. На Windows можно запустить сервер в PowerShell. Вместо примера подставьте полный origin из параметров расширения.

   ```powershell
   $env:OLLAMA_ORIGINS = 'chrome-extension://ID-ИЗ-НАСТРОЕК'
   $env:OLLAMA_HOST = '127.0.0.1:11434'
   $env:OLLAMA_NO_CLOUD = '1'
   ollama serve
   ```

4. В другом терминале выполните `ollama pull qwen3:4b-instruct-2507-q4_K_M`. Это разовая загрузка около 2,5 ГБ. Убедитесь, что тег появился в `ollama list`. Секреты, аккаунт и ключ не нужны. [Модель](https://ollama.com/library/qwen3:4b-instruct-2507-q4_K_M).
5. В окне ответа «Развернуть» показывает вопрос, ответы и поле чата. Enter отправляет, Shift + Enter переносит строку. «Копировать» копирует последний ответ. Крестик или Escape внутри панели закрывает чат. Новый вызов начинает отдельный разговор.

## Safari на Mac

- Для локального теста в поддерживающих временные расширения версиях Safari включите функции для веб-разработчиков в расширенных настройках. В разделе Developer нажмите **Add Temporary Extension…**, подтвердите запрос Safari и выберите `extension/` или ZIP. Включите расширение и предоставьте доступ для тестируемого сайта и локального сервиса, если Safari спросит. Такая установка действует до выхода из Safari или до 24 часов. В Safari 26+ для macOS сочетание команды меняется в настройках Safari. [Временная установка](https://developer.apple.com/documentation/safariservices/running-your-safari-web-extension), [сочетания клавиш](https://developer.apple.com/documentation/safari-release-notes/safari-26-release-notes), [разрешения](https://developer.apple.com/documentation/safariservices/managing-safari-web-extension-permissions).
- Для сборки приложения на Mac установите полный Xcode и выберите его в Xcode → Settings → Locations → Command Line Tools. Из этой папки выполните команду ниже. Укажите свой уникальный Bundle ID при запросе. В старом Xcode инструмент называется `safari-web-extension-converter`. Проверьте предупреждения по manifest, выберите команду подписи для app и extension, соберите и запустите приложение, затем включите расширение в Safari → Settings → Extensions. Для неподписанной локальной сборки следуйте режиму разработки Apple. [Упаковка и параметры Xcode](https://developer.apple.com/documentation/safariservices/packaging-a-web-extension-for-safari).

  ```sh
  xcrun safari-web-extension-packager ./extension --macos-only --swift --app-name "Ответ рядом" --project-location ./dist/safari
  ```

- Включите Ollama с origin именно Safari и повторите проверку ниже. Мобильный Safari в эту конфигурацию не входит, поскольку адрес 127.0.0.1 на iPhone указывает на сам телефон.

## Проверка

- Выделите «Какой спутник у Земли? А) Луна Б) Марс». Ожидается короткий ответ по-русски с выбором А. Разверните и спросите «Why is B wrong?». Ответ должен быть по-английски и учитывать, что B — Марс.
- Повторите у нижнего и правого края экрана и при прокрутке страницы. Проверьте копирование, закрытие, пустое выделение и новый вопрос после закрытия. Остановите Ollama, проверьте сообщение об ошибке, затем запустите сервер и нажмите «Повторить».
- Рабочая область — основной документ обычных HTTP(S)-страниц, включая выделение в текстовом поле. Выделение внутри вложенных фреймов, страницы настроек браузера и встроенные PDF-просмотрщики не поддерживаются. Сайты могут запрещать встраивание панели своей политикой безопасности. При отказе копирования ответ можно выделить в панели и скопировать вручную.
- Запустите модульные проверки командой `node --test tests/model.test.mjs` (Node 22+). Сквозной тест для Chrome for Testing использует временный профиль и тестовый сервер вместо модели. Для воспроизведения остановите Ollama, чтобы освободить порт 11434. Запустите Chrome for Testing 156 с параметрами `--headless --remote-debugging-port=0 --enable-unsafe-extension-debugging --user-data-dir=<временный-профиль> --load-extension=<полный-путь-к-extension>`. Выполните `node tests/browser.mjs <временный-профиль>/DevToolsActivePort`. Тест посылает браузеру клавиши Alt + Shift + Q и отдельно вызывает действие значка. Для проверки с настоящей Ollama оставьте сервер включённым и добавьте к команде теста флаг `--live`.
- При 403 сверьте origin и перезапустите сервер, при 404 загрузите точный тег модели. При отсутствии связи проверьте `ollama list`, разрешение браузера на доступ к локальному сервису и порт 11434. На слабом компьютере первый ответ может занять больше времени. Ожидание ограничено двумя минутами.

### Результаты проверки 3 ноября 2026 года

На macOS Chrome for Testing 156.0.8078.80 и Microsoft Edge 156.0.4314.58 загрузили распакованное расширение. На тестовой HTTPS-странице автоматизация выделила английский вопрос с вариантами и отправила браузеру Option + Shift + Q. В обоих браузерах реальная локальная модель ответила по-русски. На «Why is option B wrong?» она ответила по-английски и связала вариант B с Венерой из исходного выделения.

В обоих браузерах проверены размещение панели у края экрана, отсутствие горизонтальной прокрутки, разворачивание, передача текста операции копирования, закрытие и пустое выделение. Контрольный сервер отдельно подтвердил состав тела запроса, отсутствие Referer и текста за пределами выделения, сохранение истории и повтор после HTTP 503 без дублирования реплики. Обработчик копирования проверялся без изменения системного буфера обмена. Прошли 10 модульных тестов.

Safari 26.6.2 проверен с временным расширением на локальной HTTP-странице. Сочетание Option + Shift + Q открыло панель. После добавления Safari в OLLAMA_ORIGINS сервер вернул короткий русский ответ. В развёрнутом чате модель учла исходный вопрос, но на английское уточнение ответила по-русски. Для этой версии Ollama в конце Safari origin нужен символ * после полного UUID. Подписанная сборка и публикация не проверялись.

## Сборка и публикация

`python3 package.py` создаёт архив в `dist/` из перечисленных файлов расширения. Архив имеет manifest.json в корне. Политика, сравнение сервисов, тесты, файлы соседних проектов и их настройки в архив не входят.

- **Chrome Web Store.** Зарегистрируйте аккаунт разработчика, загрузите ZIP через Developer Dashboard. Добавьте описание единственной функции, иконки, снимки экрана, инструкции рецензенту по запуску Ollama. В Privacy practices укажите обработку выделенного содержимого и переписки на устройстве, обоснуйте разрешения и дайте публичную ссылку на политику. Это раскрытие нужно и при локальной обработке. Отправьте на проверку. [Публикация](https://developer.chrome.com/docs/webstore/publish), [правила пользовательских данных и минимальных разрешений](https://developer.chrome.com/docs/webstore/program-policies/user-data-faq).
- **Microsoft Edge Add-ons.** Используйте аккаунт разработчика в Partner Center и загрузите тот же ZIP. Заполните карточку. В разделе Privacy укажите назначение, разрешения, использование данных, отсутствие удалённого исполняемого кода и доступный URL политики. Добавьте инструкции для проверки и отправьте на сертификацию. [Порядок публикации и поля Privacy](https://learn.microsoft.com/en-us/microsoft-edge/extensions/publish/publish-extension).
- **Mac App Store.** Подготовьте подписанное приложение-контейнер через Xcode или используйте упаковку Safari Web Extension в App Store Connect. В приложении разместите инструкцию по включению расширения и настройке Ollama, ссылку на политику, иконки и контакт поддержки. В App Store Connect заполните App Privacy по фактическому поведению всего приложения, добавьте URL политики, снимки экрана, требования к модели и шаги для App Review. Перед отправкой протестируйте сборку на текущей версии Safari. [Варианты упаковки](https://developer.apple.com/safari/extensions/), [App Privacy](https://developer.apple.com/app-store/app-privacy-details/), [App Review §§ 4.4 и 5.1](https://developer.apple.com/app-store/review/guidelines/).

В карточке магазина поясните, что activeTab даёт временный доступ после действия пользователя, scripting читает выделение и размещает панель в этой вкладке, разрешение для 127.0.0.1 нужно для локальной Ollama. В манифесте шаблон хоста охватывает порты loopback, но код и политика connect-src ограничивают соединение портом 11434. Единственный ресурс, доступный веб-страницам, — оболочка панели. Содержимое чата выдаётся только окну текущего вызова. Фонового чтения сайтов, истории и хранилища у расширения нет.

Перед подачей разместите текст PRIVACY.md по публичному HTTPS-адресу и укажите реальный контакт издателя. Сравнение вариантов и источники — в SERVICES.md.
