Ответ рядом

Выделите вопрос вместе с нужными вариантами ответа. Нажмите Alt / Option + Shift + Q или значок расширения. «Развернуть» открывает чат. Enter отправляет сообщение, Shift + Enter добавляет строку.

Локальная модель

Установите Ollama. Закройте её уже запущенный сервер и в терминале запустите новый с указанными ниже параметрами. Команда подходит для macOS и Linux.



В другом терминале загрузите модель один раз (около 2,5 ГБ).
ollama pull qwen3:4b-instruct-2507-q4_K_M


Данные
Запросы уходят в Ollama по адресу http://127.0.0.1:11434/api/chat. Пользовательские данные в запросе — выделенный текст и реплики текущего чата. Первая реплика задаёт вопрос, а каждый следующий запрос включает предыдущие ответы для контекста. При закрытии окна или уходе со страницы расширение удаляет переписку. Адрес страницы и история просмотров не передаются. Ключ не нужен.


Клавиши
Chrome — chrome://extensions/shortcuts. Edge — edge://extensions/shortcuts. Safari 26+ для macOS — сочетание команды можно изменить в настройках Safari. Если сочетание занято, используйте значок на панели браузера.
